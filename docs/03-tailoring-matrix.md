# Standards compliance and tailoring matrix

This prototype is designed to NASA standards with documented tailoring. It is **not** certified compliant with any of them. Each row says how we meet a requirement area, or why we do not.

Status key: **C** complies · **P** partially complies · **T** tailored (met a different way, with rationale) · **N/A** not applicable to a ground prototype.
